## 🚀 Featured Projects

### 🧍 Human Pose Estimation
A multi-backend desktop application for human pose estimation from images, webcam streams, and video files.  

Built using a modern hybrid architecture combining:
- OpenCV
- MediaPipe Pose
- YOLO Pose
- Python
- React
- Tauri
- Rust

The application uses a backend-independent pose architecture and a persistent Python sidecar for local inference.  
### 🚗 Vehicle Detection using YOLOv4
Video-based object detection using YOLOv4 and OpenCV DNN with confidence filtering, Non-Maximum Suppression, and CUDA-based inference.

The project demonstrates:
- Video-frame processing
- YOLOv4 inference
- Bounding-box visualization
- Confidence filtering
- Non-Maximum Suppression
- CUDA-based inference
### 🤖 Rule-Based Conversational Chatbot
A lightweight Python conversational system using tokenization, keyword matching, response scoring, required-word validation, and fallback handling.  

Instead of relying on machine-learning models or external AI APIs, the project uses:  
- Text preprocessing
- Keyword matching
- Probability-based response scoring
- Required-word validation
- Random fallback responses

The project demonstrates the fundamentals behind simple conversational systems.
